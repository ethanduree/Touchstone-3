# North Star Bakery — Touchstone 3

Four-page responsive HTML/CSS website continuing Touchstone Task 2.

## Preview locally
Open `index.html` in a browser, or serve this folder with `python -m http.server 8000` and visit `http://localhost:8000`.

## Publish
Upload the contents of this folder to a **public** GitHub repository, then enable GitHub Pages (Settings → Pages → Deploy from a branch → main / root). Paste the repository URL and the published Pages URL into the Word submission template. No URLs have been invented.

## Notes
The contact form is a demonstration only; it does not transmit or store data. The bakery address and opening hours were not supplied. Pricing is illustrative. All media are the provided North Star Bakery assets.
